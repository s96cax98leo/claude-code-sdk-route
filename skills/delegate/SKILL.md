# 把工作交給 sdk-route 的 API session

API session 是另一個完整的 Claude Code：有同一份 plugin、skill、agent、CLAUDE.md 與記憶，但**看不到這段對話**，而且花的是使用者 API 金鑰的錢。所以只在使用者要求時使用，不要自己決定把工作搬過去。

全部操作都透過工具 `mcp__sdk-route__session`，參數 `command` 與 `/sdk-route` 後面的文字相同。工具沒出現時先用 ToolSearch 載入；再沒有就請使用者 `/reload-plugins`。

## 流程

1. **看現況**：`status`。已有 session 在跑就沿用，不要再開。
2. **開 session**：`open [模型] --cwd <專案的絕對路徑>`。要接著上次的工作用 `resume`。回覆說「已在執行中」時再呼叫一次即可。
3. **交辦**：`say <派工單>`。寫法見下一節。
4. **等待**：`wait`（預設最多等 120 秒，可寫 `wait 300`）。它在「這一輪結束、而且沒有背景工作在跑」或「有問題等回答」時回來，並附上最近的對話。還在跑就再 `wait`，不要用 `status` 密集輪詢。
5. **處理它的提問**：見〈誰來決定〉。
6. **驗收**：`log` 讀完整回覆，再自己用便宜的方式查證關鍵聲稱（檔案在不在、測試是否真的通過、`git log`、`git status`）。它的回報和任何 subagent 一樣可能過度樂觀。
7. **回報使用者**：做了什麼、放在哪、花了多少（`cost`）、還有什麼等使用者決定。除非使用者要關，否則不要 `close`，使用者可能想在 pane 接著問。

pane 是使用者視窗裡的畫面。由你開的 pane 在終端寬度不足時不會自動出現，交辦後告訴使用者可以用 `/sdk-route show` 打開、`/workflow` 看背景工作。

## 派工單怎麼寫

它只知道你寫進去的東西。一張派工單要能單獨讀懂：

- **目標**：要做出什麼，為什麼要做。
- **位置**：專案與檔案的絕對路徑、分支、要讀的文件。指路徑，不要把檔案內容貼進去。
- **已知事實**：你在主 session 已經查到、它查不到的東西（例如用瀏覽器看到的頁面結構）。
- **限制**：不能碰的檔案、不能做的動作（推送、開 PR、合併、連外、對真實服務操作）。
- **完成條件**：怎樣算做完，要跑哪些檢查。
- **回報格式**：要它列出改了哪些檔案、跑了什麼指令與結果、沒做到的部分。
- **停下來的時機**：遇到需要使用者決定的事就停下來問，不要自行假設。

一次交一件範圍清楚的事。後續補充用新的 `say`，它會記得前面的內容。

## 誰來決定

- **權限詢問**（`yes`／`always`／`no`）：只有使用者已經明確同意過這類操作時才代答，否則轉述給使用者。session 預設是略過權限模式，通常不會問。
- **它的選擇題**（`answer <編號>` 或 `say <自己的回答>`）：使用者在對話中已經決定過的，照使用者的決定回答；沒決定過的，把題目和選項原樣轉給使用者，附上你的建議。
- **AgentWorkFlow 的閘門**（plan、design、deliver、merge 等核准）：一律由使用者決定，不可代為核准，也不要叫它「先核准再說」。
- **會花錢或不可逆的事**（推送、發佈、刪除、對真實網站操作）：先問使用者。

轉述時把完整選項寫出來，使用者不一定看得到 pane。使用者回答後，一次把所有題目答完，避免多來回幾輪。

## 留在主 session 做的事

- 需要登入帳號的工具：Claude in Chrome、claude.ai 的連接器（文件、artifact）。API session 沒有這些。先在這裡查好，再把事實寫進派工單。
- 改 sdk-route 自己的程式。改完需要 `/reload-plugins`，會中斷正在跑的 API session，所以等它停在閘門或做完再請使用者重新載入。

## 省錢與穩定

- **模型**：預設 sonnet；機械性的大量工作用 haiku；很難的設計或除錯才用 opus 或 fable。
- **不要在工作中途重新載入或重開**：`resume` 會把整段對話重新送一次，長對話一次可能要一美元上下。
- **每過一個段落就 `say /compact`**；整件事做完、要換題目時才 `say /clear`。專案規則寫在 CLAUDE.md，要它長期記住的事請它「記住」，兩者在清除後都還在。
- **每次用 Bash `cd` 之後回到原本的專案資料夾**。mod 用主 session 目前的資料夾找金鑰檔與專案，跑掉會出現「金鑰池是空的」。
- 同一時間只有一個 API session。

## 金鑰

金鑰由使用者自己填在 `.claude/sdk-route.env`。不要讀出、印出或轉述金鑰內容，不要把它設成 shell 的 `ANTHROPIC_API_KEY`；畫面與回報只提標籤（A、B）。回報「金鑰池是空的」或金鑰無效時，請使用者自己處理。

## 指令速查

| 指令 | 用途 |
|---|---|
| `status` | 狀態、金鑰標籤、模型、花費、最近幾行 |
| `open [模型] [--cwd 路徑] [--ask]` | 開新的 session；`--ask` 表示照常詢問權限 |
| `resume` | 接回上一個 session（回到它原本的專案） |
| `say <訊息>` | 交辦或回話；`say /compact`、`say /clear`、`say /model <名稱>` |
| `wait [秒]` | 等到這一輪與背景工作結束，或有問題要回答 |
| `log` | 最近 40 行對話與待回答的問題 |
| `answer <編號…>` | 回答選擇題 |
| `yes`／`always`／`no` | 回答權限詢問 |
| `workflow` | 讓 pane 顯示 workflow 與背景工作 |
| `loaded` | 它載入了哪些 plugin、skill、agent、MCP |
| `cost` | 今天、本專案、全部的花費 |
| `stop` | 中斷目前這一輪 |
| `close` | 結束 session 並關閉 pane |
